# Proyecto Final - Programacion Paralela y Concurrente

Este repositorio contiene el proyecto final de Programacion Paralela y Concurrente.

## Archivos principales

- secuencial.cpp: codigo secuencial base.
- Linea_Base_Paralela_de_la_IA.cpp: linea base paralela generada con IA usando OpenMP.
- Benchmark_Schedulers_TareaA.cpp: evaluacion de schedulers static, dynamic y guided.
- Histograma_Sincronizacion_FalseSharing.cpp: histograma de colores, sincronizacion y false sharing.
- SPMD_Afinidad_TareaB.cpp: version SPMD/SIMD y pruebas de afinidad.

## Resultados

El repositorio incluye archivos CSV y TXT con los resultados de las pruebas realizadas.

## Historial

El historial de commits comienza con el codigo secuencial base, despues la linea base paralela generada con IA y finalmente las optimizaciones manuales con OpenMP.
